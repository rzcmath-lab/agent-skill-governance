# Ownership and Admission

Each rule should have one clear owner.

- Put workflow instructions in the skill that performs the workflow.
- Put cross-cutting constraints in a shared policy only when several skills genuinely consume them.
- Link to an existing rule instead of copying it.
- If ownership is ambiguous, reject or defer the candidate rather than creating a second source of truth.

Admission is a semantic decision, not a file-placement exercise. The reviewer must consider duplicates, contradictions, scope, evidence strength, and disclosure risk together.
